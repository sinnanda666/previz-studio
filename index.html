시작하기
새 프로젝트는 기본 카메라 한 대와 환경광만 제공합니다. 공간 탭에서 배우와 바닥을 추가하세요. 씬 구성에서 폴더를 만들고 객체를 드래그하거나 이동 메뉴로 정리할 수 있습니다. 상단 길이(초)에서 1~1800초를 설정할 수 있습니다. 기본 60초, 24fps이며 기존 키와 컷보다 짧게 줄일 수 없습니다.
  1. 웹사이트를 Chrome 등 WebGL 지원 브라우저에서 엽니다. 인터넷 연결이 필요합니다. 비회원도 편집할 수 있습니다.
  2. 공간 탭에서 바닥과 필요한 에셋을 추가해 첫 장면을 구성합니다.
  3. 정지 후 공간 탭에서 배우나 소품을 선택하고 위치를 바꿉니다.
  4. 촬영 탭에서 렌즈를 바꾸고 컬러 탭에서 색감을 조절합니다.
  5. PNG 스틸과 프로젝트 .previz 파일을 저장합니다.
화면 구성
왼쪽은 시나리오·에셋·씬 구성·연기, 가운데 위는 편집용 Scene View, 아래는 촬영 결과 Cinematic View, 오른쪽은 선택 객체와 카메라·환경·컬러 속성입니다. 하단 작업 탭은 관련 패널을 열며 컬러 탭은 촬영 모니터를 확대합니다.
시나리오 텍스트는 메모용입니다. 작성한 내용이 자동으로 연기나 공간으로 변환되지는 않습니다.
에셋과 공간 편집
  1. 에셋 탭에서 인물·가구·소품·건축·조명·카메라 분류를 선택합니다. 검색창으로 이름을 찾고 카드를 클릭하면 씬에 추가됩니다.
  2. 내 GLB 가져오기를 눌러 파일을 선택합니다. 가져온 에셋 카드를 다시 누르면 같은 모델을 추가할 수 있습니다.
  3. Scene View에서 사물을 클릭하거나 씬 구성에서 이름을 선택합니다. 이동·회전·크기 버튼으로 기즈모 모드를 바꾸고 축을 드래그합니다. 오른쪽 객체 속성에서도 수치를 수정할 수 있습니다.
  4. 빈 공간 드래그로 시점을 회전하고 휠로 확대합니다. 탑뷰로 위에서 배치를 확인합니다.
  5. 객체 패널에서 복제, 잠금, 숨김, 바닥 맞춤, 25cm 격자 스냅을 사용합니다. 거리 측정 버튼은 선택 객체의 외곽 크기를 상태 표시줄에 보여줍니다. 잠긴 객체는 씬 구성에서 다시 선택해 잠금을 해제합니다.
GLB는 일반 복제 대신 가져온 에셋 카드를 사용하세요. 기본 배경 구조물은 개별 편집이 제한됩니다.
연기와 키프레임
  1. 배우를 선택하고 애니메이션의 모션 / 리깅 탭에서 자동 걷기·대기·걷기·앉기 중 하나를 고릅니다. 관절 슬라이더로 기본 자세에 오프셋을 더합니다.
  2. 애니메이션이 포함된 GLB는 선택 후 GLB 모션 목록에서 클립을 고릅니다.
  3. 이동을 만들려면 정지 상태에서 도프 시트에서 0프레임을 선택하고 배우를 배치한 뒤 키 삽입 버튼 또는 I를 누릅니다.
  4. 96프레임으로 이동해 배우를 다른 위치에 배치하고 다시 키를 삽입합니다. 재생하면 선택한 보간 방식(선형 / 완만 / 고정)에 따라 위치와 회전이 변화합니다.
이미 키프레임을 기록한 배우는 시간 이동 시 기존 위치가 다시 적용될 수 있습니다. 기본 키프레임은 위치와 회전을 기록하며 광원은 광량·색상·조사각도 보간합니다. 정교한 IK나 모션 블렌딩은 아직 지원하지 않습니다.
촬영 · 카메라 바디와 센서
  1. 공간 → 에셋에서 카메라를 추가하고 촬영 탭의 활성 카메라에서 선택합니다. 자동 컷을 끄면 수동 선택을 유지할 수 있습니다.
  2. 카메라 바디에서 RED KOMODO 6K, KOMODO-X, ARRI, Sony, Blackmagic, Canon 등의 프리셋을 선택합니다. 센서 폭·높이(mm)는 직접 수정할 수 있습니다. 높이 0은 폭 기준입니다.
  3. 렌즈 mm를 낮추면 넓게, 높이면 좁게 보입니다. 같은 렌즈라도 센서 사용 영역이 작으면 화각이 좁아집니다.
  4. 센서 촬영 모드에서 전체 센서, 크롭 또는 사용자 지정 모드를 선택합니다. 사용 영역 폭·높이 %와 화면비를 조절하고 유효 센서 및 화각 정보를 확인합니다. KOMODO 계열의 6K~2K 모드는 중앙 윈도우의 비례 근사이며 실제 기록 해상도를 변경하지 않습니다.
  5. 씬 구성에서 카메라를 선택해 이동·회전합니다. 피사체 추적을 지정하면 카메라 방향이 대상에 맞춰집니다.
카메라 바디와 센서 값은 프리비즈용 대표 규격이며 실제 장비의 모든 기록 모드와 일치하지 않을 수 있습니다.
렌즈 · 아나모픽 · 디스퀴즈
촬영 → 카메라 설정에서 렌즈 유형을 선택합니다. 구면 단렌즈는 초점거리, 구면 줌렌즈는 줌 범위와 현재 렌즈 mm를 설정합니다. 아나모픽은 1.33×, 1.5×, 1.6×, 1.8×, 2× 스퀴즈를 지원합니다.
  1. 아나모픽을 선택하고 스퀴즈 배율을 지정합니다.
  2. 모니터 디스퀴즈를 켜면 복원된 화면을, 끄면 압축된 화면을 확인할 수 있습니다.
  3. 렌즈 왜곡을 음수로 조절하면 배럴, 양수로 조절하면 핀쿠션 왜곡이 적용됩니다. 0은 왜곡 없음입니다.
실제 렌즈별 왜곡, 플레어, 보케를 정밀하게 재현하는 기능은 아닙니다.
피사계 심도 · 아웃포커싱 · 랙 포커스
촬영 탭에서 피사계 심도 사용을 켜고 조리개(f값)와 초점 거리(m)를 설정합니다. 여기서 초점 거리는 피사체까지의 초점 설정 거리이며 렌즈 초점거리(mm)와 다릅니다. 낮은 f값은 일반적으로 얕은 심도를 만듭니다.
씬에서 카메라 앞의 배우나 소품을 선택하고 선택 객체에 초점을 누르면 활성 카메라의 초점 거리가 해당 객체 위치를 기준으로 설정됩니다. 지속적인 자동 초점 추적은 아닙니다.
랙 포커스 실습
  1. 카메라 앞 2m와 5m 지점에 피사체를 배치합니다.
  2. 재생을 멈추고 0초에서 초점 거리 2m를 입력한 뒤 현재 시간에 초점 키 추가를 누릅니다.
  3. 3초로 이동해 5m를 입력하고 다시 초점 키를 추가합니다.
  4. 재생하여 초점 이동을 확인합니다. 초점 키 전체 삭제로 기록을 지울 수 있습니다.
초점 키는 위치·회전 키와 별개이며 선형 보간됩니다. 심도는 깊이 기반 근사 효과로 GPU 성능에 영향을 줄 수 있습니다. 느리거나 화면이 이상하면 피사계 심도를 끄세요.
환경 에셋과 광원 실습
조명 분석은 직접광 근사이며 실제 측광값을 대체하지 않습니다. 환경에서 천문 기반 자연광을 켤 수 있고, 부감도 출력에서 조명 배치도와 장비 리스트를 선택할 수 있습니다. 환경설정의 그래픽 품질은 미리보기 성능을 조절합니다.
공간 → 에셋에서 자연 또는 야외 분류를 선택합니다. 카드를 클릭해 추가하고 씬 뷰에서 이동·회전·크기를 조절합니다. 복제하여 숲이나 거리를 구성하고 씬 구성에서 폴더로 정리합니다.
숲 / 골목 / 실내
숲: 흙 바닥, 활엽수, 침엽수, 풀, 바위를 배치하고 안개를 조절합니다. 골목: 도로, 인도, 건물, 자동차, 가로등 소품을 배치합니다. 실내: 바닥, 벽, 창문, 침대 또는 소파를 배치합니다. 가로등 소품은 자체 발광하지 않으므로 별도 광원을 추가합니다.
광원 설정
에셋에서 광원을 추가하고 선택한 뒤 객체 속성에서 포인트(전방위), 스포트(집중광), 디렉셔널(평행광)을 선택합니다. 광량, 색온도, 색상, 거리, 감쇠, 조사각, 가장자리, 그림자를 조절합니다. 조사각과 가장자리는 스포트에 해당합니다. 실제 조도 측정값은 아닙니다.
씬 구성
폴더를 추가하고 객체 이름을 드래그하여 정리합니다. 검색창으로 이름을 찾고 더블클릭으로 이름을 바꿉니다. 오른쪽 표시 및 잠금 버튼을 사용합니다.
기본 에셋은 간략한 3D 모델이며 실제 사진 수준의 재질이나 식생 시뮬레이션은 아닙니다. 고품질 모델은 GLB 가져오기를 이용하세요.
날씨 설정
조명 페이지의 환경 패널에서 날씨, 강도, 바람, 강수 범위를 선택하세요. 재생하면 비와 눈이 움직이며 촬영 화면에도 반영됩니다. 창밖 모드는 기본 샘플의 뒷벽 바깥에 강수를 배치합니다. 폭우 번개는 6.2초에 발생합니다.
수면과 파도
수면 객체를 선택하면 객체 속성에서 파고, 파장, 파속, 포말을 조절할 수 있습니다. 재생 시간에 따라 파도가 움직입니다.
편집 · 컷과 쇼트리스트
활성 카메라를 선택하고 타임라인에서 원하는 시점으로 이동한 뒤 현재 시간에 카메라 컷 추가를 누릅니다. 다른 시간에 다른 카메라를 지정해 컷을 구성합니다. 자동 컷을 켜고 재생하여 전환을 확인합니다. 현재 컷 삭제로 전환을 제거할 수 있습니다. 쇼트 메모는 직접 작성하며 쇼트리스트 CSV는 출력 메뉴에서 저장합니다.
컬러와 LUT
  1. 하단 컬러 탭을 엽니다. Lift(암부), Gamma(중간톤), Gain(밝은톤), Offset(전체) 휠을 드래그해 색을 바꾸고 아래 슬라이더로 밝기를 조절합니다. 휠을 더블클릭하면 색 방향이 중앙으로 돌아옵니다.
  2. 룩에서 Neutral, Warm film, Cool night, Monochrome을 선택하거나 .cube 불러오기로 외부 LUT를 적용합니다. LUT 강도로 혼합 비율을 조절합니다.
  3. 노출·채도·대비, 필름 그레인, 비네팅을 조절하고 원본 비교 체크박스로 컬러 처리 효과를 비교합니다.
  4. 휘도 히스토그램에서 밝기 분포를 확인합니다. 초기화 버튼은 컬러 휠을 초기화합니다.
렌더 RGB 기반 근사 색보정이며 다빈치의 Log 변환·색관리와 동일하지 않습니다. 원본 비교는 모든 렌더 설정을 초기화하는 기능이 아닙니다.
환경 프리셋
공간 → 에셋에서 환경 프리셋을 선택하고 추가하세요. 기존 객체는 유지되며 새 컬렉션에 개별 편집 가능한 객체가 추가됩니다. 우주 프리셋은 야간 환경으로 전환합니다. 모델과 수면은 간략한 프리비즈용 표현입니다.
재생·저장·출력
재생/일시정지, 정지, 시간 슬라이더로 설정한 전체 길이를 탐색합니다. 자동 컷은 직접 등록한 카메라 전환을 적용합니다. 쇼트 버튼은 해당 시작 시간으로 이동합니다.
씬뷰의 부감도 출력에서 촬영 배치도 (동선 포함), 현재 씬뷰 그대로, 수직 부감도 (정사영) 중 선택합니다. 해상도(1920 / 2560 / 3840px), 격자, 카메라·조명 가이드, 키프레임 동선 및 시간 표시를 설정합니다. 미리보기에서 결과를 확인하고 필요하면 미리보기 갱신을 누른 뒤 PNG 저장을 누릅니다. 배치도는 객체 위치와 키프레임을 평면에 표시하며 실제 이동 곡선이나 건축 도면과 정확히 일치하지 않을 수 있습니다. 상단 PNG 스틸은 현재 촬영 화면을, 쇼트리스트 CSV는 쇼트 정보를 내보냅니다. 프로젝트 저장은 로컬 .previz(JSON) 파일을 다운로드하며 불러오기로 복원합니다. 서버 저장 및 자동 복구는 제공하지 않습니다.
주의: JSON에는 기본 객체, 위치·회전·크기, 키프레임, 기본 배우 모션, 카메라 바디·센서·크롭·렌즈·심도·초점 키와 쇼트, 시나리오가 저장됩니다. 가져온 GLB와 잠금·숨김, 날씨 및 수면 설정은 포함됩니다. 지형, 재질, 광원 설정, 자연광 및 스크립트로 생성한 객체도 프로젝트 데이터에 포함됩니다. LUT, 배경 이미지 및 일부 컬러·환경 설정은 보존되지 않습니다. 원본 에셋을 별도로 보관하세요. 자동 저장과 영상 출력은 미지원입니다.
개인 스튜디오 · 작업 타이머 · 반려슬레이트
왼쪽 로그인 / 회원가입에서 계정을 만들 수 있습니다. 비회원도 편집과 로컬 저장을 사용할 수 있습니다. 작업 시작을 누르면 작업 시간이 기록되고 종료 시 누적 시간과 보상이 반영됩니다. 창을 닫아도 종료하지 않은 타이머는 계속 진행될 수 있으므로 작업을 마치면 직접 종료하세요.
칭호 옆 →에서 해금된 칭호를 선택하고, 반려슬레이트 이름 옆 →에서 이름과 외형을 관리합니다. 슬레이트 스튜디오의 보관함·상점·도감에서 외형, 장신구, 소품을 확인하고 필름 조각으로 구매하거나 장착합니다. 계정 관련 기록과 달리 영화 프로젝트는 서버에 저장되지 않습니다.
스크립트 작업실 · AI 공간 생성
상단 환경설정 왼쪽의 스크립트 버튼을 누릅니다. PREVIZ SCRIPT STUDIO는 JSON 명령 배열을 받아 기존 씬에 객체를 추가합니다. 시나리오 메모와는 별개입니다.
  1. AI용 명세를 눌러 표시된 명세를 복사하고 AI에게 원하는 공간과 함께 전달합니다.
  2. AI가 작성한 JSON 배열만 입력창에 붙여넣습니다. 마크다운 코드 울타리는 제거합니다.
  3. 검증 및 실행을 누르고 로그를 확인합니다. 닫은 뒤 전체 보기 또는 촬영 탭에서 확인합니다.
  4. 실행 취소로 생성 작업을 되돌릴 수 있습니다. 프로젝트 저장과 스크립트 저장(.pvscript)은 별개입니다.
첫 실습
[
 {"shape":"box","name":"바닥","position":[0,-0.1,0],"size":[8,0.2,6],"material":{"preset":"tile","repeat":8}},
 {"shape":"box","name":"기둥","position":[-3,1.5,-2],"size":[0.4,3,0.4],"repeat":[2,1,3],"step":[6,0,2],"batch":true},
 {"actor":true,"name":"배우","motion":"walk","keyframes":[{"time":0,"position":[0,0,2]},{"time":4,"position":[0,0,-2]}]},
 {"camera":true,"position":[2,1.6,5],"lookAt":[0,1,0],"lens":35,"cutAt":0}
]
프로젝트 길이는 4초 이상이어야 합니다. 자동 컷을 켜고 재생합니다. 위치와 크기는 m, 회전은 도, 시간은 초입니다. Y가 높이입니다.
명령어 사전
shape: box, sphere, cylinder, cone, torus, wedge, arch, stairs. name, position, size, rotation, color(#RRGGBB). repeat와 step은 XYZ 반복 수와 간격이며 batch:true는 도형을 인스턴스로 묶습니다. 선택 배치 분리로 개별 편집할 수 있으나 잠긴 배치 등은 제한됩니다.
material: preset, roughness, metalness, opacity(0~1), emissive, emissiveIntensity(0~5), repeat(0.25~32). 발광 재질은 실제 광원이 아닙니다.
asset: AI용 명세에 표시되는 에셋 ID 사용. size는 상대 배율이며 color, material, batch:true는 지원하지 않습니다.
architecture: room 또는 wall. width, height, thickness, room의 depth와 ceiling, openings 배열. 개구부 wall은 front/back/left/right(단독 벽은 front), offset은 벽의 음의 방향 끝에서부터의 거리, bottom은 바닥 기준 높이입니다. width와 height로 구멍을 지정합니다. 문짝과 창틀은 별도로 배치합니다.
actor: true, height(130~220cm), motion(idle/walk/sit/auto). camera: true, lens(8~300mm), body, aperture, focusM, lookAt, cutAt. light: point/spot/directional, power, kelvin, color, angle, distance, shadow, lookAt.
keyframes: time, position, rotation, interpolation(linear/smooth/hold), 광원 전용 power/color. 시간은 오름차순이며 프로젝트 길이 이내여야 합니다. 생략한 값은 이전 값 유지. 반복·배치·건축 명령에는 키를 넣지 마세요. cutAt은 카메라 전용이며 기존 동일 시간 컷을 교체합니다.
제한 및 오류
64 KiB, 실행당 생성 300개(반복·건축 확장 포함), 객체당 키 120개, 실행당 키 1000개. 배우 20명, 카메라 12대, 광원 12개/실행. 복합 에셋과 그림자 광원에는 추가 예산이 있습니다. 임의 JS/Python은 실행하지 않습니다. 모든 생성은 브라우저에서 처리됩니다. 오류 로그를 확인하고 명령을 나누거나 수치를 수정하세요. 실행 전 프로젝트 저장을 권장합니다.


지형·재질·대규모 공간
공간 프리셋의 카테고리와 공간을 선택해 추가합니다. 학교 캠퍼스처럼 큰 공간은 전체 보기로 맞추고 탑뷰로 배치를 확인합니다. 캠퍼스는 사진 기반 근사 모델이며 실측 도면이 아닙니다.
Scene View의 지형 편집 → 새 지형 30m 또는 기존 지형 선택 → 융기/깎기/스무딩/평탄화/색상 칠하기. 반경과 강도를 설정해 좌클릭 드래그하고 편집을 종료하면 카메라 회전으로 돌아갑니다. 지형 초기화는 기존 변형을 지우므로 주의하세요.
객체 속성의 재질 라이브러리에서 재질, 색상, 거칠기, 금속성 등을 조절합니다. 숲·갈대밭 등 대량 식생 에셋은 반복 배치에 적합하며 개별 나무 편집이나 실제 식생 시뮬레이션을 보장하지 않습니다.


조명 장비·효과·분석
조명 에셋에서 Fresnel, HMI, COB LED, 패널, 튜브 등 장비를 선택하고 객체 속성에서 광량, 디머, 색온도, 틴트, 젤, 조사각, 그림자를 조절합니다. 소프트박스·그리드·스누트 등은 광량과 빔 형태의 근사 효과입니다.
스포트 광원의 고보 패턴, 회전, 크기로 창문·블라인드 등의 무늬를 설정합니다. FX에서 깜빡임, 촛불, 번개, 경찰등 등 시간 기반 효과를 설정하고 재생합니다. 플래그 등 그립은 배치할 수 있지만 반사판의 간접광과 실제 확산은 재현하지 않습니다.
Cinematic View의 조명 분석에서 광원 비교, 직접광 추정 및 히트맵을 확인합니다. 차폐·반사·고보를 포함한 정밀 측광이 아닙니다. 환경의 천문 기반 자연광은 날짜, 시간, 위도·경도, 시간대, 북쪽 방향에 따른 태양 위치를 근사합니다. 부감도 출력에서 조명 배치도와 장비 리스트를 PNG로 저장할 수 있습니다.


성능·그래픽 품질
상단 환경설정 → 그래픽 품질에서 저사양/표준/고사양/사용자 설정을 선택합니다. 느리면 미리보기 해상도, 그림자 해상도, 날씨 밀도, 수면 갱신 FPS를 낮추고 편집 화면 그림자와 미리보기 심도를 끕니다. 상태 표시줄의 FPS와 draw calls는 참고용입니다.
반복 도형은 batch:true를 활용하고 실제 광원과 그림자 수를 줄이세요. 대형 GLB와 복합 캠퍼스 에셋은 브라우저 메모리와 GPU를 사용합니다. PNG 스틸은 현재 모니터 품질을 사용하며 부감도 해상도는 별도입니다. 프로젝트는 자동 저장되지 않으므로 새로고침 전에 저장하세요.
단축키와 문제 해결
⌘ Z 실행 취소 · ⌘ ⇧ Z 다시 실행 · ⌘ D 복제. Windows에서는 Ctrl을 사용합니다. 입력창에 포커스가 있으면 편집 단축키가 적용되지 않습니다. 상단 실행 취소 / 다시 실행 버튼으로도 조작할 수 있습니다. 최대 50단계의 일부 객체 편집 및 컬렉션 변경을 지원합니다. 상단 초기화는 확인 후 빈 프로젝트를 다시 열며 되돌릴 수 없습니다. 먼저 저장하세요.
엔진 로딩이 멈추면 인터넷 연결과 Chrome의 WebGL/그래픽 가속을 확인하고 다시 열어보세요. GLB 오류는 Blender에서 텍스처가 포함된 GLB로 다시 내보내 보세요. 스크립트 버튼이 비활성화되어 있으면 엔진 초기화를 기다리세요. 계속 비활성화되면 브라우저 콘솔 오류를 확인하세요. 재생이 느리면 환경설정에서 저사양을 선택하세요. 새로고침 전에 프로젝트를 저장하세요.
