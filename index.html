에셋 라이브러리의 보기 메뉴에서 목록 / 간단 목록 / 아이콘을 전환할 수 있습니다. 검색창에서 이름이나 분류를 검색하고 항목을 클릭하여 배치하세요.

환경 에셋과 광원 실습

공간 → 에셋에서 자연 또는 야외 분류를 선택합니다. 카드를 클릭해 추가하고 씬 뷰에서 이동·회전·크기를 조절합니다. 복제하여 숲이나 거리를 구성하고 씬 구성에서 폴더로 정리합니다.

숲 / 골목 / 실내

숲: 흙 바닥, 활엽수, 침엽수, 풀, 바위를 배치하고 안개를 조절합니다. 골목: 도로, 인도, 건물, 자동차, 가로등 소품을 배치합니다. 실내: 바닥, 벽, 창문, 침대 또는 소파를 배치합니다. 가로등 소품은 자체 발광하지 않으므로 별도 광원을 추가합니다.

광원 설정

에셋에서 광원을 추가하고 선택한 뒤 객체 속성에서 포인트(전방위), 스포트(집중광), 디렉셔널(평행광)을 선택합니다. 광량, 색온도, 색상, 거리, 감쇠, 조사각, 가장자리, 그림자를 조절합니다. 조사각과 가장자리는 스포트에 해당합니다. 실제 조도 측정값은 아닙니다.

씬 구성

폴더를 추가하고 객체 이름을 드래그하여 정리합니다. 검색창으로 이름을 찾고 더블클릭으로 이름을 바꿉니다. 오른쪽 표시 및 잠금 버튼을 사용합니다.

기본 에셋은 간략한 3D 모델이며 실제 사진 수준의 재질이나 식생 시뮬레이션은 아닙니다. 고품질 모델은 GLB 가져오기를 이용하세요.

날씨 설정

조명 페이지의 환경 패널에서 날씨, 강도, 바람, 강수 범위를 선택하세요. 재생하면 비와 눈이 움직이며 촬영 화면에도 반영됩니다. 창밖 모드는 기본 샘플의 뒷벽 바깥에 강수를 배치합니다. 폭우 번개는 6.2초에 발생합니다.

시작하기

새 프로젝트는 기본 카메라 한 대와 환경광만 제공합니다. 공간 탭에서 배우와 바닥을 추가하세요. 씬 구성에서 폴더를 만들고 객체를 드래그하거나 이동 메뉴로 정리할 수 있습니다. 상단 길이(초)에서 1~1800초를 설정할 수 있습니다. 기본 60초, 24fps이며 기존 키와 컷보다 짧게 줄일 수 없습니다.

  1. ZIP을 풀고 HTML을 Chrome에서 엽니다. 인터넷 연결과 WebGL이 필요합니다.
  2. 공간 탭에서 바닥과 필요한 에셋을 추가해 첫 장면을 구성합니다.
  3. 정지 후 공간 탭에서 배우나 소품을 선택하고 위치를 바꿉니다.
  4. 촬영 탭에서 렌즈를 바꾸고 컬러 탭에서 색감을 조절합니다.
  5. PNG 스틸과 프로젝트 JSON을 저장합니다.

화면 구성

왼쪽은 시나리오·에셋·씬 구성·연기, 가운데 위는 편집용 Scene View, 아래는 촬영 결과 Cinematic View, 오른쪽은 선택 객체와 카메라·환경·컬러 속성입니다. 하단 작업 탭은 관련 패널을 열며 컬러 탭은 촬영 모니터를 확대합니다.

시나리오 텍스트는 메모용입니다. 작성한 내용이 자동으로 연기나 공간으로 변환되지는 않습니다.

에셋과 공간 편집

  1. 에셋 탭에서 인물·가구·소품·건축·조명·카메라 분류를 선택합니다. 검색창으로 이름을 찾고 카드를 클릭하면 씬에 추가됩니다.
  2. 내 GLB 가져오기를 눌러 파일을 선택합니다. 가져온 에셋 카드를 다시 누르면 같은 모델을 추가할 수 있습니다.
  3. Scene View에서 사물을 클릭하거나 씬 구성에서 이름을 선택합니다. 이동·회전·크기 버튼으로 기즈모 모드를 바꾸고 축을 드래그합니다. 오른쪽 객체 속성에서도 수치를 수정할 수 있습니다.
  4. 빈 공간 드래그로 시점을 회전하고 휠로 확대합니다. 탑뷰로 위에서 배치를 확인합니다.
  5. 객체 패널에서 복제, 잠금, 숨김, 바닥 맞춤, 25cm 격자 스냅을 사용합니다. 거리 측정 버튼은 선택 객체의 외곽 크기를 상태 표시줄에 보여줍니다. 잠긴 객체는 씬 구성에서 다시 선택해 잠금을 해제합니다.

GLB는 일반 복제 대신 가져온 에셋 카드를 사용하세요. 기본 배경 구조물은 개별 편집이 제한됩니다.

연기와 키프레임

  1. 배우를 선택하고 애니메이션의 모션 / 리깅 탭에서 자동 걷기·대기·걷기·앉기 중 하나를 고릅니다. 관절 슬라이더로 기본 자세에 오프셋을 더합니다.
  2. 애니메이션이 포함된 GLB는 선택 후 GLB 모션 목록에서 클립을 고릅니다.
  3. 이동을 만들려면 정지 상태에서 도프 시트에서 0프레임을 선택하고 배우를 배치한 뒤 키 삽입 버튼 또는 I를 누릅니다.
  4. 96프레임으로 이동해 배우를 다른 위치에 배치하고 다시 키를 삽입합니다. 재생하면 위치와 회전이 선형 보간됩니다.

이미 키프레임을 기록한 배우는 시간 이동 시 기존 위치가 다시 적용될 수 있습니다. 키프레임은 위치와 회전만 기록하며 정교한 IK나 모션 블렌딩은 아직 지원하지 않습니다.

촬영과 조명

  1. 촬영 탭에서 활성 카메라를 선택합니다. 자동 컷을 끄면 재생 중에도 수동 선택을 유지할 수 있습니다.
  2. 렌즈 mm를 낮추면 넓게, 높이면 좁게 보입니다. 센서 폭 또는 Full Frame·Super 35·APS-C 프리셋과 화면비를 조절합니다.
  3. 카메라 자체를 이동·회전하려면 씬 구성에서 선택합니다. 피사체 추적 목록에서 배우를 지정하면 카메라 방향이 자동으로 조정됩니다.
  4. 조명 탭에서 낮·황혼·밤, 태양 강도, 환경광, 색온도, 안개, 그림자를 조절합니다. 에셋에서 광원을 추가할 수도 있습니다.
  5. 배경 사진 가져오기로 환경 배경을 변경합니다. 시간대를 다시 변경하면 배경이 초기화될 수 있습니다.

센서 프리셋과 광원은 근사 시뮬레이션이며 실제 노출계나 물리적 조도 측정값이 아닙니다.

컬러와 LUT

  1. 하단 컬러 탭을 엽니다. Lift(암부), Gamma(중간톤), Gain(밝은톤), Offset(전체) 휠을 드래그해 색을 바꾸고 아래 슬라이더로 밝기를 조절합니다. 휠을 더블클릭하면 색 방향이 중앙으로 돌아옵니다.
  2. 룩에서 Neutral, Warm film, Cool night, Monochrome을 선택하거나 .cube 불러오기로 외부 LUT를 적용합니다. LUT 강도로 혼합 비율을 조절합니다.
  3. 노출·채도·대비, 필름 그레인, 비네팅을 조절하고 원본 비교 체크박스로 컬러 처리 효과를 비교합니다.
  4. 휘도 히스토그램에서 밝기 분포를 확인합니다. 초기화 버튼은 컬러 휠을 초기화합니다.

렌더 RGB 기반 근사 색보정이며 다빈치의 Log 변환·색관리와 동일하지 않습니다. 원본 비교는 모든 렌더 설정을 초기화하는 기능이 아닙니다.

환경 프리셋

공간 → 에셋에서 환경 프리셋을 선택하고 추가하세요. 기존 객체는 유지되며 새 컬렉션에 개별 편집 가능한 객체가 추가됩니다. 우주 프리셋은 야간 환경으로 전환합니다. 모델과 수면은 간략한 프리비즈용 표현입니다.

재생·저장·출력

재생/일시정지, 정지, 시간 슬라이더로 설정한 전체 길이를 탐색합니다. 자동 컷은 직접 등록한 카메라 전환을 적용합니다. 쇼트 버튼은 해당 시작 시간으로 이동합니다.

상단 PNG 스틸은 현재 촬영 화면을, 쇼트리스트 CSV는 쇼트 정보를 내보냅니다. 프로젝트 저장은 JSON을 다운로드하며 불러오기로 복원합니다.

주의: JSON에는 기본 객체, 위치·회전·크기, 키프레임, 기본 배우 모션, 카메라 렌즈와 쇼트, 시나리오가 저장됩니다. 외부 GLB, LUT, 배경 이미지, 컬러·환경 설정, 잠금·숨김은 보존되지 않습니다. 원본 에셋을 별도로 보관하세요. 자동 저장과 영상 출력은 미지원입니다.

단축키와 문제 해결

⌘ Z 실행 취소 · ⌘ ⇧ Z 다시 실행 · ⌘ D 복제. Windows에서는 Ctrl을 사용합니다. 입력창에 포커스가 있으면 편집 단축키가 적용되지 않습니다. 상단 실행 취소 / 다시 실행 버튼으로도 조작할 수 있습니다. 최대 50단계의 일부 객체 편집 및 컬렉션 변경을 지원합니다. 상단 초기화는 확인 후 빈 프로젝트를 다시 열며 되돌릴 수 없습니다. 먼저 저장하세요.

엔진 로딩이 멈추면 인터넷 연결과 Chrome의 WebGL/그래픽 가속을 확인하고 다시 열어보세요. GLB 오류는 Blender에서 텍스처가 포함된 GLB로 다시 내보내 보세요. 재생이 느리면 그림자를 끄거나 브라우저 창 크기를 줄이세요. 새로고침 전에 프로젝트를 저장하세요.
